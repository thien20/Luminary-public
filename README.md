# Luminary

**See any codebase's architecture in seconds.**

Luminary is a VS Code extension that turns an unfamiliar repository into a clear, evidence-backed map of how it actually works — its files, dependencies, routes, and APIs — instead of leaving you to piece it together by hand.

## Demo

[![Luminary demo video](https://img.youtube.com/vi/xBmTwkoZAmU/maxresdefault.jpg)](https://youtu.be/xBmTwkoZAmU)

## Features

- **Instant ingest** — point Luminary at your open workspace, a GitHub URL, or pasted code, and it indexes the repo in seconds.
- **Real parsing, not guesswork** — full AST parsing for JavaScript/TypeScript (symbols, imports, exports), with support for Go.
- **Artifact Dependency Graph** — automatically derives a codebase-wide graph of components, routes, APIs, and config, with every edge backed by file/line evidence and a confidence score.
- **Runs where you code** — a native VS Code panel, no context-switching to a separate app.
- **Private repo support** — works with private GitHub repos via a personal access token.

## Status

Luminary is in private beta. This repo is a public showcase — [watch the demo](https://youtu.be/xBmTwkoZAmU) to see it in action.
